#  problem dmopc14c5p1 المشكلة 2

ملاحظات تقنية لمسألة Core Drill (dmopc14c5p1)القانون الرياضي: المسألة تطبيق مباشر لحجم المخروط: $V = \frac{1}{3} \pi r^2 h$.استخدام الثوابت: يفضل استخدام math.pi من مكتبة math لضمان أعلى دقة عشرية ممكنة بدلاً من كتابة $3.14$ يدوياً.ترتيب العمليات: في البرمجة، يُفضل حساب البسط كاملاً ثم القسمة على المقام لضمان الدقة: (pi * r**2 * h) / 3.التعامل مع المدخلات:استخدم int(input()) لتحويل النص القادم من input إلى رقم صحيح ليقبل العمليات الحسابية.الدالة int() تتجاهل المسافات (Spaces) تلقائياً لكنها تنهار (Crash) إذا احتوى النص على حروف.تحسين الأداء (Performance): ضغط الأسطر يقلل استهلاك الذاكرة (Memory) والوقت (Runtime) بجزء ضئيل جداً، لكن في المشاريع الحقيقية الأولوية للكود النظيف (Clean Code) والمنظم.الدقة العشرية: ناتج القسمة في بايثون 3 يعطي دائماً نوع float (رقم عشري)، وهو المطلوب في مخرجات هذه المسألة.
