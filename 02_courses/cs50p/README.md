# CS50 Python

This repository contains my work from **CS50's Introduction to Programming with Python (CS50P)**, focusing on the early weeks of the course and the foundational Python concepts introduced during that stage.

## Contents

The repository currently covers:

* **Week 0** — lecture practice and personal notes
* **Week 1** — lecture practice and personal notes
* **Week 2** — lecture practice and personal notes

Each week contains the Python practice files produced while studying the corresponding course material, along with my own `notes.md` documentation.

## Repository Scope

This repository contains **lecture practice and learning notes** from CS50P.

The **CS50P Problem Sets are maintained separately in a private repository** and are therefore not included here.

This separation keeps the different types of coursework organized while allowing this repository to focus specifically on lecture-based learning and practice.

## Learning Notes

The `notes.md` files contain my personal study notes and understanding of the material covered during each week.

They are intended to document my learning process rather than reproduce the original course material.

## Lecture Scripts

Full lecture scripts/transcripts are intentionally **not included** in this repository.

The repository contains my own notes instead of reproductions of the course lectures. This keeps the repository focused on my learning artifacts while respecting the copyright of the original course material.

## Learning Context

CS50P is part of my broader Python learning journey and provides additional practice with Python fundamentals alongside the structured learning resources in my Python Backend Engineering roadmap.

The work preserved here represents the learning stage at which it was produced. It is not intended to represent the complete CS50P course or a polished production-level Python codebase.
