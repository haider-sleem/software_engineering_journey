# Phase One — Tests

This directory contains the test files and testing-related work produced during Phase One.

It is organized by learning resource and is intended to provide a dedicated location for automated tests as testing practices are developed throughout the roadmap.

## Resources

| Resource            | Test Work                            |
| ------------------- | ------------------------------------ |
| Learn to Code       | [View Tests](./learn_to_code/)       |
| Python Crash Course | [View Tests](./python_crash_course/) |

## Testing Approach

Testing was introduced during Phase One as part of the learning process.

Some initial test files and test attempts were created while studying Python testing. However, systematic testing was not treated as a fully developed practice throughout the phase.

As the learning progressed, I recognized that effective testing requires understanding testing concepts, tools, test design, and appropriate testing practices rather than relying on practice alone.

For this reason, testing was intentionally deferred for deeper study and more systematic application in later stages of the roadmap.

The test files preserved in this directory therefore represent the testing work and structure produced during Phase One. Their presence should not be interpreted as comprehensive test coverage.

## Organization

The tests are organized according to the corresponding learning resource:

* **`learn_to_code/`** contains tests related to the exercises and source code from *Learn to Code by Solving Problems*.
* **`python_crash_course/`** contains tests related to the exercises and source code from *Python Crash Course*.

This organization mirrors the structure used in `src/`, making the relationship between source code and tests easier to navigate.

## Learning Stage

The testing work in this directory reflects an early stage of learning.

Testing practices, test design, test organization, fixtures, mocking, coverage, and other testing techniques will be developed more systematically as the roadmap progresses.

Later testing work may therefore differ significantly in structure and quality from the early test files preserved here.

## Relationship to Source Code

The tests correspond to source code maintained under `src/`.

* **[`src/`](../src/README.md)** contains the source code, exercises, and practical implementations.
* **`tests/`** contains the corresponding testing work.

The resource-level test directories follow the same resource-based organization used by the source code.

## Phase One Scope

This directory reflects the testing-related work actually produced during Phase One.

It does not claim complete test coverage or comprehensive testing proficiency. Instead, it preserves the testing artifacts and learning decisions made during this stage of the roadmap.
