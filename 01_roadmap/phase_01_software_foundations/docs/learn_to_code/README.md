# Learn to Code by Solving Problems — Resource Overview

**Book Title:** *Learn to Code by Solving Problems: A Python Programming Primer*
**Author:** Daniel Zingaro
**Publisher:** No Starch Press, 2021

---

## Role in Phase One

*Learn to Code by Solving Problems* is a foundational resource in Phase One of my Python Backend Engineering roadmap.

It was used to develop programming fundamentals, problem-solving skills, algorithmic thinking, and an early understanding of algorithm efficiency.

Some concepts introduced in this book will be explored in greater depth in later phases. For example, the book introduces **Big O Notation**, while **Algorithms & Data Structures** are planned for deeper study in **Phase Two**.

## Learning Transparency

The solutions and other learning artifacts associated with this resource are maintained separately from these study notes in [`src/learn_to_code/`](../../src/learn_to_code/README.md).

Their presence in the repository represents the final work preserved from the learning process and should not be interpreted as a direct measure of my ability to solve every problem independently from scratch at the time of study.

My ability to solve problems varied considerably depending on the problem. This distinction is documented to provide a transparent representation of my actual learning progress.
